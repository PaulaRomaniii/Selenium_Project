# Selenium Project

This project is built with **Selenium WebDriver** to automate web application testing.

## 🚀 Features Tested
- Navigate between pages
- Hovering functions
- Filling forms
- File upload & download
- Dark mode functionality
- Key pressing automation
- Sorting tables
- Notification assertions
- Checking broken images
- Checkboxes toggle

## 🛠️ Tools & Tech
- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA
